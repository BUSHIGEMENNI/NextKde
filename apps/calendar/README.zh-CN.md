# KOS 日历

**[English](README.md) | [中文](README.zh-CN.md)**

KOS 日历是独立的 Qt Quick 应用，不导入 Quickshell 运行时，也不依赖 `desktop/` 下的文件。

## 当前状态

应用现在可以独立构建和安装。参考 macOS 日历的布局提供月、周、日视图、迷你月历、搜索和日程列表，并支持全天/定时事件、重复规则预设、提醒以及 iCalendar 导入导出。KOS 待办中设置了日期的任务会与事件一同显示，并保留清单颜色和完成状态。带版本的 D-Bus PIM 服务负责 KCalendarCore 持久化和桌面通知，界面不会直接读写数据文件。

## 日历与待办联动

- 所有设置了截止日期的待办都会进入日历；重复待办由 PIM 服务按当前可见范围展开。
- 新建或编辑事件时可以启用“同时在 Todo 中显示为任务”，并选择目标清单和优先级。
- 关联后的标题、备注、日期时间、全天状态和可编辑的重复规则会双向同步；在 Todo 中完成任务后，日历会立即反映完成状态。
- 关联项目只由日历事件发送提醒，避免同一事项出现两次桌面通知。
- 删除任意一端或关闭关联时都会保留另一端，只解除关系，避免意外丢失数据。

## 构建

在仓库根目录执行：

```bash
cmake --preset calendar-dev
cmake --build --preset calendar-dev
```

可执行文件位于 `.build/calendar-dev/apps/calendar/`。

## 第一版边界

- 已包含：月/周/日视图、迷你月历、搜索、选中日期议程、事件增删改、带日期待办的显示与编辑、事件/任务关联、时区感知的本地存储、全天事件、重复规则预设、提醒、iCalendar 文件、键盘快捷键和屏幕阅读器标签。
- 暂缓：拖拽改期、时区选择界面、参会人调度、高级重复规则编辑、云账户、CalDAV 和 Akonadi 集成。

日历和待办只共享 `Kos.Pim` 契约与服务，不互相导入应用代码。数据归属、兼容规则和安全限制见 `docs/PimArchitecture.md`。

## 紧凑界面

日历采用 nextkdeAppDemo 的 GalleryDesign 2.9：224px 普通侧栏、26px 液态工具栏
操作、28px 实色表单字段及紧凑弹窗底栏。月网格与选中日期日程使用平面内容材质；
日程高度随条目数量变化，较长列表在限定高度内滚动。周／日视图的初始位置和窗口
缩放都限制在有效滚动范围内。事件／任务编辑器保留原有校验和删除确认，公共底栏
只发出操作请求。

液态材质在共享 UI 边界显式接入。源码预览须使用重新构建、包含
`LiquidCompactSurface` 的日历二进制，旧版已安装程序无法加载这份源码。

## 材质对齐（GalleryDesign 2.10）

液态工具栏按钮保留玻璃边缘，不额外增加强调色焦点环。连续普通侧栏仅对背景
采用 0.95 不透明度与 QML 同窗底面模糊，文字保持不透明。
菜单、事件详情和下拉选项使用一层液态面板，内部条目保持普通填充。弹层留在
同一窗口，采样排除自身；编辑器下拉框采样当前编辑面板。减少透明度或缺少
GPU 采样时使用不透明回退，不依赖 KWin 液态插件。
日／周／月／年选择器通过共享液态组件采样同一工具栏底面，轨道与滑动选中块
使用中性玻璃，不叠加强调色焦点框；保留键盘选择和不透明回退。
按压时采样透镜放大至 1.12 倍并增强折射，切换时滑动并以 OutBack 曲线回弹。
快速点击和键盘切换也保留短暂膨胀反馈；文字及点击区域固定，减少动态效果时直接归位。
字体、工具栏搜索、选择器尺寸、表单几何及编辑器底栏尺寸保留此前紧凑设计。
